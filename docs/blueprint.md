# **App Name**: Gerente Ágil

## Core Features:

- Cadastro de Produtos: Interface para cadastrar produtos com nome, descrição, preço e quantidade.
- Listagem de Produtos: Listagem de produtos cadastrados, exibindo suas informações.
- Registro de Vendas: Interface para registrar vendas, associando produtos e quantidades.
- Histórico de Vendas: Visualização do histórico de vendas com detalhes de produtos e valores.
- Cálculo de Totais: Cálculo automático do total de vendas e do estoque atualizado.
- Sugestão de Reposição: Sugestão inteligente, implemented using a tool, de produtos a serem repostos com base no histórico de vendas.

## Style Guidelines:

- Cor primária: Azul claro (#A7D1AB) para transmitir confiança e organização, refletindo a eficiência da gestão.
- Cor de fundo: Branco suave (#F5F5F5) para proporcionar um ambiente clean e facilitar a leitura das informações.
- Cor de destaque: Laranja vibrante (#FFA500) para botões de ação e alertas importantes.
- Fonte: 'Inter' (sans-serif) para títulos e textos, oferecendo uma leitura clara e moderna.
- Ícones simples e intuitivos para representar ações e informações na loja.
- Layout responsivo para visualização em diversos dispositivos (desktop e mobile).
- Transições suaves para carregamento de informações e alertas.
